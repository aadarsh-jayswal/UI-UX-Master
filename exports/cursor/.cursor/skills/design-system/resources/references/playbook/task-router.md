## Reviewing or writing code: CSS property → principles

When the input is code, check every declared value of these properties against the listed entries (not only the ones that look wrong at a glance):

| Property / pattern | Check against |
|---|---|
| `color` (text) | [TYP-07](principles/15-typography.md#typ-07) (pure #000/#fff, heading darker than body), [TYP-09](principles/15-typography.md#typ-09) (contrast), [VH-04](principles/02-visual-hierarchy.md#vh-04) |
| `background-color` on pills/badges, buttons, pages | [CON-01](principles/06-contrast.md#con-01), [COL-01](principles/14-color.md#col-01), [COL-02](principles/14-color.md#col-02), [CNS-02](principles/11-consistency.md#cns-02), [DLG-01](principles/18-dialogs.md#dlg-01) |
| `font-family` | [TYP-02](principles/15-typography.md#typ-02), [TYP-03](principles/15-typography.md#typ-03) |
| `font-size` | [TYP-11](principles/15-typography.md#typ-11), [TYP-12](principles/15-typography.md#typ-12), [VH-03](principles/02-visual-hierarchy.md#vh-03) |
| `font-weight` | [TYP-08](principles/15-typography.md#typ-08), [TYP-10](principles/15-typography.md#typ-10) (below 400 on body/UI text) |
