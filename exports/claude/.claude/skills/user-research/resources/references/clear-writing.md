# Clear writing

Re-authored from Johnathan Mo's `ste` skill (MIT; see licenses). Apply to every deliverable: findings, specs, explanations, notes and handoffs.

Write so the reader understands on the first pass without losing technical accuracy.

- Start with what the thing does or what the verdict is, and why it matters.
- One main idea per sentence. Prefer common, concrete words. Keep a correct technical term and define it the first time; expand acronyms on first use.
- Use active voice and name the actor: say which component, rule or person does each thing.
- State cause and effect directly. Put steps in the order they happen.
- Separate confirmed behaviour, assumptions and recommendations, and label each.
- Use a short example when an idea is abstract. Use lists for steps or parallel items and prose when the ideas depend on each other; use tables only for comparisons and before/after fixes.
- Remove filler, vague intensifiers and decorative jargon. Do not trade accuracy for brevity: if a detail is uncertain, say what is unknown and what would verify it.

Before finishing, check that every pronoun has a clear referent, every term is defined or familiar to the reader, and each step says what changes and why. This follows the goals of clear technical communication; it does not certify ASD-STE100 compliance.
