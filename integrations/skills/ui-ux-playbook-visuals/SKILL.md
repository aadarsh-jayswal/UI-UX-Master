# UI/UX playbook visuals

Optional image pack for the ui-ux-master collection. The principle text, checks and corrections are in the core skills' playbook (`resources/references/playbook/`); this pack only holds pictures.

1. Find the principle ID (for example `VH-01`, `FRM-02`) from the core playbook's task router, or search the [examples gallery](examples-gallery.md) for the topic.
2. Open the image listed for that ID and show or describe it. Each image's banner says what it is:
   - **SOURCE CROP**: a crop of the PDF figure. Pink thumbs-down marks the incorrect version; green thumbs-up marks the correct one.
   - **RECREATED ILLUSTRATION**: an original drawing that restates the lesson; not copied artwork.
3. Name the PDF page from the gallery when the user wants to find the original. The [coverage map](coverage-map.md) lists what was extracted from each of the 144 pages.

Source crops are from a third-party PDF and are kept for personal reference; do not publish or redistribute them. When an image cannot be displayed, describe the "What differs" column instead of claiming the user saw it.
