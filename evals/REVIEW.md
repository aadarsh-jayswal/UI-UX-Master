# Architecture review

Review type: static review of authored contracts and expected scenario routes, 2026-10-23. This is not an executed LLM benchmark or a claim of native host discovery. Machine tests separately exercise file materialization and safeguards.

| Scenario | Expected route | Boundary checked | Static result |
|---|---|---|---|
| Small UI correction | ui-design-toolkit implement | No forced audit/research/motion/prototype set | Contract supports direct scoped work |
| New product interface | Interface owner; conditional research/system stages | No mandatory all-skill chain or invented user evidence | Stages are optional and ownership is explicit |
| Existing-product audit | improve-ui audit | Read-only; contract/runtime/correction proof | Review cannot silently become implementation |
| Accessibility fix | fixing-accessibility remediate | No whole-product audit prerequisite | Targeted behavior verification owns completion |
| Motion-specific request | animate selected platform | Web/Expo loaded separately; read-only review modes | Shared policy removes contradictory unconditional timing/property claims |
| Unavailable integration | Router integration check | No fabricated execution/install/auth or provider substitution | Independent briefing can proceed; dependent step remains named |

Revisions incorporated: explicit one-writer ownership, no recursive router handoffs, standards-tagged accessibility claims, isolated picker width exception, provider verification honesty, existing authorization survives internal handoffs, and minimal direct invocation. Both taxonomy files were compared and reconciled.

For behavioral validation, run each request from scenarios.json in a clean host/project with a realistic source/design fixture. Record selected skill, files actually loaded, output, product mutations, checks, and deviations. Do not give the model the expected route first. Test focused specialist invocation and router-mediated work. Review outputs and make only evidence-supported corrections.

Remaining limitations: native Claude/Codex/Cursor invocation not executed by this review; real screen-reader/device/browser feel checks need those environments; vendor services and optional scripts were not run.
